Installation guide

Windows 10/11 or macOS 12+ · Premiere Pro or After Effects 2023 or newer · Read me

1

Extract the zip

Put it somewhere it can stay. The plugin reads its models from this folder.

  1. Windows: right-click Bunnys Caption v1.2.0.zip → Extract All… · Mac: double-click the zip.
  2. Choose a folder you will keep, for example E:\Bunnys Caption → Extract.
Don't extract to Downloads or Desktop if you clean them often. If this folder is deleted or moved, captions stop working until you point the plugin to it again (step 4).
2

Open Bunnys Caption v1.2.0›Offline Files. Delete the folders you don't need to save space.

3

Install the plugin

One double-click. Open Bunnys Caption v1.2.0›Plugin first.

Windows

  1. Close Premiere Pro.
  2. Double-click Install on Windows.bat.
    If Windows warns you: More info → Run anyway.
  3. Wait for Done, then press any key.

Mac

  1. Quit Premiere Pro.
  2. Double-click Install on Mac.command.
    If macOS blocks it: right-click the file → Open → Open.
  3. Answer Y to install the speech engine (needs Homebrew and internet, once).
  4. Wait for All done!, then press any key.

Open it

Open Premiere Pro or After Effects and any project → Window → Extensions → Bunnys Caption. Dock the panel anywhere. In After Effects, open the composition you want to caption first.

The installer copies the plugin into Premiere and turns on Adobe's PlayerDebugMode, which Premiere needs to load panels that aren't signed by Adobe. It only affects your user account.

Manual install on Windows only if the installer fails

  1. Copy the Plugin folder.
  2. Paste this in the File Explorer address bar and press Enter (create extensions if it's missing):
    %APPDATA%\Adobe\CEP\extensions
  3. Paste the folder there and rename it to com.bunnysframelab.caption.
  4. Press Windows key → type cmd → open Command Prompt → paste and press Enter:
    for %v in (11 12 13) do reg add "HKCU\Software\Adobe\CSXS.%v" /v PlayerDebugMode /t REG_SZ /d 1 /f
  5. Open Premiere → Window → Extensions → Bunnys Caption.

Manual install on Mac only if the installer fails

  1. Open Terminal (Applications → Utilities) and paste each line, pressing Enter after each:
    mkdir -p ~/Library/Application\ Support/Adobe/CEP/extensions
    for v in 11 12 13; do defaults write com.adobe.CSXS.$v PlayerDebugMode 1; done
    brew install whisper-cpp
  2. In Finder press Shift+Cmd+G, paste ~/Library/Application Support/Adobe/CEP/extensions and press Enter.
  3. Copy the Plugin folder there and rename it to com.bunnysframelab.caption.
  4. Open Premiere → Window → Extensions → Bunnys Caption.
4

Connect the engine and model

Once, in the Bunnys Caption panel.

  1. Settings tab → Offline files → Choose folder.
  2. Select Bunnys Caption v1.2.0›Offline Files → Select Folder.
  3. Click Install all from folder and wait for Installed: … (on Mac it only finds the models).
  4. Settings → Processor: Auto (GPU if installed) with NVIDIA, CPU only without. On Mac leave it on Auto: the Homebrew engine uses the Apple GPU by itself.
  5. Settings → Model: pick the model for your language (table below).

Make your first captions

  1. Open a sequence with your video.
  2. Generate tab → Language → Transcribe.
  3. Check the text → Add captions. Each caption lands on the timeline as its own clip.

If something isn't right

ProblemFix
Not in Window → ExtensionsRun the installer again, then quit Premiere completely and reopen it.
The panel opens blankClose Premiere, run the installer again.
Mac: "Speech engine not installed"Open Terminal and run brew install whisper-cpp, then restart Premiere.
Mac: translation does not startOpen Terminal and run brew install llama.cpp.
"Engine not installed" or no modelsRepeat step 4 and make sure you picked the Offline Files folder.
"No empty video track"Sequence → Add Tracks → add 1 video track.
Wrong or missing fontInstall the font in Windows, or pick another one in the Customize tab.
Anything elseSettings → Run self-test. The report is saved to %APPDATA%\BunnysFramelab\BunnysCaption\selftest.log
UninstallClose Premiere, double-click Uninstall on Windows.bat or Uninstall on Mac.command in the Plugin folder. Saved styles stay in %APPDATA%\BunnysFramelab (Windows) or ~/Library/Application Support/BunnysFramelab (Mac).
